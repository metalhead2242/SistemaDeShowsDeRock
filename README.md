# SistemaDeShowsDeRock
sistema de gerenciamento de eventos de rock 
🏍️ Rock & Ride Festival Manager 🎸
Sistema desenvolvido em Python para gerenciamento de um festival beneficente voltado à comunidade motociclista e fãs de rock.

  
📖 Sobre o Projeto
O Rock & Ride Festival Manager é um sistema em Python executado via terminal, criado para auxiliar na organização de eventos beneficentes envolvendo motociclismo e música rock. O projeto aplica conceitos fundamentais de programação como funções, listas, dicionários, estruturas de repetição, condicionais e modularização.

🎯 Objetivo
Gerenciar categorias de motos participantes.
Controlar bandas e line-up do festival.
Automatizar operações de cadastro, consulta e remoção.
Disponibilizar informações do evento e FAQ.
Simular arrecadações beneficentes por meio de doações.
⚙️ Funcionalidades
✅ Visualizar Line-up do Festival
✅ Consultar motos permitidas
✅ Adicionar bandas
✅ Remover bandas
✅ Filtrar bandas por gênero musical
✅ Sistema de doações simuladas
✅ FAQ com dúvidas frequentes
